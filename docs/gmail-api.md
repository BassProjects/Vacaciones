# Integración Gmail API retirada

Este documento describía la integración de la primera versión Python. Por decisión
posterior del responsable el 22-09-2026, se ha sustituido por SMTP con contraseña.
No se usan las llamadas a Gmail API ni las credenciales OAuth. La configuración
vigente y sus límites de red están en [smtp.md](smtp.md). El correo sigue pausado
hasta disponer de SMTP autorizado por la plataforma y un buzón configurado.
